# Finalize — Slice 5: SSH Tunneling

**Branch:** `slice-5-ssh` → merged to `main`. **Date:** 2026-05-22.

## Task-done summary
Real local SSH port-forward (russh, pure Rust) so a DB connection can tunnel through a bastion. When a connection has SSH enabled, the tunnel opens first, the driver URL is retargeted to the local forward (`127.0.0.1:<ephemeral>`), and the tunnel is torn down on disconnect/delete. SSH secrets (password / key passphrase) live in the OS keychain under `ssh:<conn_id>`, never in JSON — connection bundles stay secret-free.
