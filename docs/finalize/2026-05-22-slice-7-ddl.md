## Task-done summary
Create-table structure editor with **preview-then-apply** migration SQL. The user fills a column grid (name/type/nullable/default/PK), clicks Preview to see the exact dialect-quoted SQL, then Apply to run it. DDL generation is pure Rust so quoting/qualification is correct and unit-tested; CREATE/DROP/ALTER (add/drop column) are all supported in the backend.
