Unsigned preview builds

Unsigned previews use AGPL-3.0-only for TableIQ-owned application code. Their signing status changes macOS distribution trust, not the license. Preview releases include the installer, matching source archive, copyright and license notices, and checksums.

When sharing a preview with a teammate, share the complete release package so the source and notices travel with the installer. Unsigned previews are for local testing and are not notarized by Apple.
