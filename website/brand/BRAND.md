# TableIQ brand (Stage 4)

Source of truth: `docs/brand/TableIQ-Brand-Guidelines.pdf` and the supplied kit. This file summarizes it for the website; it invents nothing new. Name: TableIQ (decided).

- Category: Mac database client with a local MCP server for coding agents. Placed against TablePlus, TablePro, DataGrip, Tabularis, DBeaver.
- Thesis: an agent in your database should be as inspectable as your own SQL.
- Storyline: (problem) you gave your agent a database and cannot see what it ran. (turn) share only chosen connections, read-only. (promise) every query, result and refusal in view. (proof) a real session where an UPDATE was refused.
- Logo: the supplied Witness Q mark: a Q that watches, the tail as the query trace. Use supplied SVGs only; clear space one quarter of mark height; minimum 16 px mark, 96 px lockup.
- Colour: Ledger Ink #0C1A2B and Pearl #F1F6FB grounds (calm, technical). Pearl Blue #3E6694 secondary (trust). Lumen #38D6E0 on dark, Lumen Deep #0B7480 on light: the signal, used sparingly for live query traces. Violet is app AI only, never on the site.
- Type: Instrument Sans 400/500/600 for display and body, IBM Plex Mono 400/500 for code and query traces.
- Voice:
  1. Plain. Do: "Writes stay off unless you allow them." Do not: "Military-grade protection."
  2. Specific. Do: "Exercised against a 20-million-row test table." Do not: "Blazing fast at any scale."
  3. Honest about limits. Do: "Read access can still expose sensitive data." Do not: "Safe for production."
- Brand line: Let your agent in. See every query. Hero: Your Mac database client. See every agent query. Footer: An Ideolyst product.
