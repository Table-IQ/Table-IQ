# Support and sustainability

TableIQ's developer preview is free, including commercial use under its open-source license. Donations are optional and never required to unlock engines, MCP or basic protections.

## Get help

Use [issues](https://github.com/Table-IQ/Table-IQ/issues) for reproducible bugs and feature requests. Include versions and a small synthetic example. For vulnerabilities, use [SECURITY.md](SECURITY.md). The free preview has no guaranteed response time.

## Financial support

There is currently no verified active project donation checkout. The maintainer's GitHub Sponsors listing was not active when checked for this launch, so this repository does not advertise a broken sponsor link or invent a payment address.

To enable donations, the maintainer can enroll in [GitHub Sponsors](https://github.com/sponsors), complete the required identity/payout setup, publish the listing, then add its verified URL to `.github/FUNDING.yml`, the README and website. Another provider is possible after its real checkout is configured. Banking, tax and identity fields must be supplied by the owner.

Sponsorship can help maintenance but is not a dependable revenue forecast. A productive free application may have many users and little donation income.

## Paid assistance experiment

The maintainer can separately offer scoped onboarding, migration planning or support once a price, availability, deliverable and acceptance criteria are agreed. No paid plan, SLA, checkout or future feature delivery is established by this page. Contact through the maintainer's published profile route to discuss availability; never send database credentials in a public issue.

Keep any engagement bounded: named task, test environment, hours, exclusions and agreed delivery. Do not promise unlimited or lifetime support. Future individual productivity or team services need actual buyer evidence; current free features stay free.
